# Public showcase scope

This is the existing public showcase for SWARM SAR. It contains the project README, component documentation, architecture, reports, guides, planning history, benchmark definitions, recorded validation, screenshots, animations, and selected result metadata.

The frontend and its animation implementations, backend, simulator, training code, checkpoints, datasets, build scripts, and runtime configuration are not distributed here. Cloning this repository provides the showcase, not a runnable application.

## Reading the documentation

The technical documents describe the complete private project. Their commands, directory trees, code examples, and source paths are retained for context; they require access to that private implementation. Links to unavailable implementation files lead to this page and include the original path in their link title. No access to the private repository is granted by this showcase.

Historical results are recorded evidence, not fresh test runs. Capture manifests retain their original paths, commits, and hashes. Some historical media referenced by the README was recovered from the source repository's committed version for this showcase; the original working checkout was not modified. Account-specific deployment details have been removed from the public guide.
